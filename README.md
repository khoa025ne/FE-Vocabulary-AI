# FE-VocabularyAI

Frontend cho VocabularyAI — học tiếng Anh vui mỗi ngày.

Stack: Vite + React + TypeScript + Axios.

## Chạy dev

```bash
npm install
npm run dev
```

Mở http://localhost:5173

## Cấu hình API

Tạo file `.env`:

```
VITE_API_URL=http://localhost:8080
```

## Build

```bash
npm run build
```
