## Bug cần sửa

- **BUG-01 [mức độ: GÃY]**: Lệch Routing URL giữa Frontend và Backend do `server.servlet.context-path: /api`
  - **Steps**:
    1. Trên FE, thực hiện các thao tác: mở trang Khám phá từ vựng (`/words`), mở Chat AI, kiểm tra ngữ pháp (`/grammar`), hoặc bắt đầu luyện nói (`/speaking`).
    2. FE gọi các endpoint dạng `http://localhost:8080/api/words`, `http://localhost:8080/api/v1/ai/...`, `http://localhost:8080/api/ai/speaking/...`.
  - **Expected**: Backend tiếp nhận request tại các endpoint tương ứng và trả về dữ liệu 200 OK.
  - **Actual**: Backend trả về `HTTP 404 Not Found` với chi tiết `"No static resource ..."`. Nguyên nhân: `application.yml` của backend đã đặt `server.servlet.context-path: /api`, nhưng các controller (`WordController`, `ChatController`, `GrammarController`, `HintController`, `SpeakingSessionController`) lại tiếp tục khai báo `@RequestMapping("/api/...")`, khiến đường dẫn thực tế trên Tomcat bị nhân đôi thành `/api/api/...`.
  - **Response thật**:
    ```json
    {
      "type": "about:blank",
      "title": "Not Found",
      "status": 404,
      "detail": "No static resource v1/ai/conversations.",
      "instance": "/api/v1/ai/conversations",
      "properties": null
    }
    ```

- **BUG-02 [mức độ: GÃY]**: Backend thiếu endpoint root `GET /api/words` cho danh sách từ vựng
  - **Steps**:
    1. Truy cập vào trang Khám phá từ vựng trên FE (`/words`).
    2. FE gửi request `GET /api/words?page=0&size=20`.
  - **Expected**: Backend trả về danh sách từ vựng có phân trang `ApiResponse<Page<WordResponse>>` với status 200 OK.
  - **Actual**: Backend trả về `HTTP 404 Not Found`. Kiểm tra file `WordController.java`, backend chỉ định nghĩa `GET /api/words/{id}` và `GET /api/words/search`, hoàn toàn không có handler cho `GET /api/words` (hoặc `GET /`).
  - **Response thật**:
    ```json
    {
      "type": "about:blank",
      "title": "Not Found",
      "status": 404,
      "detail": "No static resource words.",
      "instance": "/api/words",
      "properties": null
    }
    ```

- **BUG-03 [mức độ: LỆCH]**: Lệch quy ước đặt tên trường Token giữa Backend (`snake_case`) và Frontend (`camelCase`)
  - **Steps**:
    1. Đăng nhập qua form `Login.tsx` với username và password hợp lệ.
    2. Kiểm tra `localStorage` sau khi đăng nhập.
  - **Expected**: `localStorage` lưu trữ đúng chuỗi JWT vào key `vocab_access` và `vocab_refresh`.
  - **Actual**: Backend trả trường `"access_token"` và `"refresh_token"` (theo annotation `@JsonProperty("access_token")` trong `AuthResponse.java`), trong khi `Login.tsx` (dòng 25) và `client.ts` (dòng 41) lại đọc `data.accessToken` và `data.refreshToken`. Kết quả là `localStorage` lưu giá trị chuỗi `"undefined"`, làm hỏng cơ chế tự động refresh token khi token hết hạn.
  - **Response thật từ BE**:
    ```json
    {
      "success": true,
      "data": {
        "access_token": "eyJhbGciOiJIUzUxMiJ9...",
        "refresh_token": "eyJhbGciOiJIUzUxMiJ9...",
        "token_type": "Bearer",
        "expires_in": 3600
      }
    }
    ```

- **BUG-04 [mức độ: LỆCH]**: Đăng nhập sai mật khẩu trả về HTTP 403 Forbidden thay vì HTTP 401 Unauthorized
  - **Steps**:
    1. Gửi request `POST /api/auth/login` với username đúng nhưng password sai.
  - **Expected**: Trả về `HTTP 401 Unauthorized` kèm theo thông báo lỗi rõ ràng như `"Sai tài khoản hoặc mật khẩu"`.
  - **Actual**: Backend trả về `HTTP 403 Forbidden` với body rỗng. Nguyên nhân: `DaoAuthenticationProvider` ném `BadCredentialsException`, nhưng chưa được xử lý tại `GlobalExceptionHandler` trước khi bị `Http403ForbiddenEntryPoint` của Spring Security bắt lại.
  - **Log thật từ BE**:
    ```text
    DEBUG o.s.s.a.d.DaoAuthenticationProvider - Failed to authenticate since password does not match stored value
    DEBUG o.s.web.servlet.DispatcherServlet - Failed to complete request: org.springframework.security.authentication.BadCredentialsException: Bad credentials
    DEBUG o.s.s.w.a.Http403ForbiddenEntryPoint - Pre-authenticated entry point called. Rejecting access
    ```

- **BUG-05 [mức độ: GÃY]**: Lệch thuộc tính Attempt ID và thiếu trường thời hạn `expiresAt` trong Quiz Attempt
  - **Steps**:
